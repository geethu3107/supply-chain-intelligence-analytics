# Dataset

This project uses the **DataCo Smart Supply Chain Dataset**.

**Dataset Source:** [Mendeley Data – DataCo Smart Supply Chain Dataset](https://data.mendeley.com/datasets/8gx2fvg2k6/5)

### Dataset Details
- **Records:** Approximately 180,519
- **Columns:** 53
- **Format:** CSV

### Instructions
1. Download the dataset from the source link above.
2. Extract the downloaded files if necessary.
3. Place `DataCoSupplyChainDataset.csv` in this `data/` folder.
4. Run the Jupyter notebook from the `notebook/` folder.

The dataset is not included in this repository. Please download it separately from the original source.
