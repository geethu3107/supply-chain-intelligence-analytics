# Supply Chain Performance & Analytics

## Project Overview
This project explores supply chain data to evaluate operational performance, shipping and logistics efficiency, delivery risk, and profitability. Using Python, the analysis identifies patterns, examines business performance, and derives insights that can support data-driven decision-making.

## Project Objectives
- Analyse overall supply chain operational performance.
- Examine shipping patterns and delivery risk.
- Evaluate sales and profitability across different business dimensions.
- Investigate the relationship between discounts and sales performance.
- Perform predictive analysis using machine learning.
- Translate analytical findings into meaningful business insights.

## Dataset
**DataCo Smart Supply Chain Dataset**

- Source: [Mendeley Data – DataCo Smart Supply Chain Dataset](https://data.mendeley.com/datasets/8gx2fvg2k6/5)
- Records: Approximately 180,519
- Features: 53 columns

The dataset contains information related to orders, customers, products, sales, shipping, and supply chain operations.

*Note: The original dataset is not included in this repository. Refer to the `data/README.md` file for download instructions.*

## Tools & Technologies
- **Python**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib & Seaborn** – Data visualization
- **Scikit-learn** – Machine learning
- **Jupyter Notebook** – Analysis and documentation

## Project Workflow

1. **Data Understanding:** Examining the dataset structure, dimensions, data types, and initial characteristics.
2. **Data Cleaning & Preprocessing:** Handling missing values, checking duplicates, converting data types, and preparing data for analysis.
3. **Operational Performance Analysis:** Exploring sales, order quantities, and performance across business dimensions.
4. **Shipping & Logistics Analysis:** Investigating shipping duration, shipping modes, and late-delivery risk.
5. **Profitability Analysis:** Examining profit patterns, loss-making areas, and profitability across different categories.
6. **Discount Analysis:** Exploring discount patterns and their relationship with sales and profitability.
7. **Predictive Analysis:** Applying a machine learning classification model to examine late-delivery risk.
8. **Business Insights:** Summarising key findings and identifying areas for operational and business improvement.

## How to Run the Project

1. Clone or download this repository.
2. Download the dataset from the Mendeley Data source.
3. Place the CSV dataset in the `data/` folder.
4. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

5. Open the Jupyter notebook and run the cells.

*Note: Update the dataset file path in the notebook if necessary to match your local folder structure.*
